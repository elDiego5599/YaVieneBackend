# Decisiones — Ya Viene

Una decisión por archivo: qué se preguntó, qué se decidió, por qué, y qué
habría pasado con la otra opción. Sirven para que nadie —el dueño dentro de
seis meses, quien entre al proyecto después— vuelva a discutir lo mismo sin
saber que ya se discutió.

Las once primeras se decidieron el **12 de septiembre de 2026**, de una
tanda. Están aquí y no repartidas por los tres repos porque varias tocan más
de uno y buscarlas sueltas es peor que tenerlas juntas; la columna dice a
cuál afecta cada una.

Una decisión no se edita: si cambia, se le añade abajo lo que cambió y desde
cuándo.
